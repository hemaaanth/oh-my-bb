Browser connection

Only pair your regular profile in BB Settings → Browser → Browser connection. Agent and sandbox profiles do not need a pairing code.

Relay uses this profile’s logins directly. Cookie export (from this profile only) supplies new isolated sessions when BB’s Share personal logins setting is on. It runs after changes and every minute, but existing sessions do not continuously sync or write back. Private windows are excluded. Agent profiles only need the extension for tab groups; no pairing required.
