# Projects

Organize native BB projects into groups. Keep project icons, ordering and routing profiles in one place.

## Native first

Projects and groups work without sibling plugins and before assignment migration. Existing assignment state is not treated as empty while an import is pending.

## Optional sources

Enable Catalog, Credentials, Agents, Status Sidebar or Task Workspaces only when needed. Integrations are off without saved consent. Loading assignment choices is explicit; unavailable definitions retain their saved IDs.

## Controlled assignment ownership

Explicit legacy import preserves existing selections. Bounded frozen exports and version-bound receipts support a single-writer handoff to each assignment owner. Forwarding starts only after activation. Rollback requires reverse reconciliation of destination edits. Destination adapters must be ready before a real handoff.

## Routing

Edit routing profiles without credentials. Configure authentication in native Configuration when using generation or Jev suggestions. Existing native composer controls, menus and agent avatars remain host-owned.
