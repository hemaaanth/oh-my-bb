# Demo Mode

Hide names and conversation content for a polished BB demo, while keeping activity visible.

## What stays visible

Demo Mode masks the real screen instead of replacing it, so nothing moves when you turn it on. Each word of a thread or project name, message, tool step, status line, running command, uncommitted-files banner, or draft becomes a solid block of the same length. Images keep their size and show a plain fill. The sidebar keeps its rows, subagents, activity counts, and status indicators. The AI model and fallback remain visible.

## Controls

Use the eye action in the sidebar footer, or press Mod+Shift+D (Command on macOS, Control elsewhere), to turn Demo Mode on or off. You can rebind the shortcut in Settings → Keyboard. Plugin pages are covered too, while the BB frame stays visible. A plugin can instead mark its own sensitive parts, such as names and messages, so its page stays readable and only those parts are masked. There are no settings. The choice stays in this browser and follows its open tabs. No account, API key, or external service is needed.

Demo Mode changes the presentation of the BB app. It is not an access-control feature: data remains in the page and newly added screens may need new masks. Check the screen before presenting.
