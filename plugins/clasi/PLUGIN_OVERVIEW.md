# Clasi

Retain scoped context, reusable lessons, and workflow feedback for BB agents.

## Keep useful guidance

- **Context** stores generalized facts and preferences.
- **Napkins** store reusable situation/action lessons.
- **Papercuts** track fixable workflow friction through open, resolved, and dismissed states.

Use Everywhere, Repository, or This worktree scope. More specific guidance overrides the same logical key in broader scopes. Review records in the Clasi panel. Native Configuration controls the active instruction budget.

## Private by default

Records stay in BB's private plugin database. Clasi does not publish or synchronize them. It never copies raw conversations automatically. Retain only generalized guidance, not messages, source excerpts, paths, secrets, personal information, or customer data.

Instruction limits do not delete stored records. Papercut details stay in the review panel; agents receive only open severity counts.

## Optional integration

Clasi runs without other Oh My BB packages. Separately installed Pinpoint can save a proposed design or copy preference after explicit learning approval in its review flow. Approval without that opt-in writes nothing. Clasi never probes, installs, or enables Pinpoint.

## Requirements

BB 0.46.1 or later. No API key, external account, or paid model service is required by Clasi. Records and settings remain local to the BB server.
