Page widths

Every page is one of three fixed widths. They shrink only when the window is narrower. A page with no .page gets narrow.

main.page · S · 46rem
Narrow: articles, reports, plans
main.page.wide · M · 62rem
Wide: wide tables, side-by-side comparisons
main.page.dashboard · L · 80rem
Dashboard: many charts in a grid

Contents

Tabs

div.tabs with one <section data-tab="Name"> per tab. Pages adds the tab row; arrow keys move between tabs. Add data-selected to open a tab other than the first. A link or contents entry that points inside a tab opens it.

Grid

div.grid puts charts or blocks side by side; columns fit the width. .cols-2 or .cols-3 fixes the count and stacks on narrow panes. Pair it with main.page.dashboard. The charts section below is one.

Compare

div.compare: two columns (or three), each opening with p.compare-label. Add positive, negative, or warning to the label for a dot. Columns take any content: text, lists, code, tables.
